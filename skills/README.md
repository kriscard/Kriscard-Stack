# Kriscard Stack skills

This directory owns:

- `kriscard-mode` — selects one workflow playbook;
- `kstack-orchestrator` — coordinates approved independent Kstack workers through the authoritative Herdr skill;
- optional personal engineering principles.

General-purpose implementation, testing, review, framework, and knowledge skills remain in [`kriscard/Skills`](https://github.com/kriscard/Skills). Herdr CLI instructions remain in [`herdrdev/herdr`](https://github.com/herdrdev/herdr). Kriscard Stack references these skills and never copies them.
